# MERN Task Manager Course

This repository will host a beginner-friendly MERN course built around a Task Manager application.

Branch strategy:
- `main`: completed production-style application after Lesson 5
- `lesson-0`: environment setup and starter backend skeleton
- `lesson-1`: backend API and MongoDB task model
- `lesson-2`: React frontend and GET tasks
- `lesson-3`: create and delete tasks with frontend integration
- `lesson-4`: update tasks, validation, and styling
- `lesson-5`: production polish, deployment readiness, and final app

Root structure:
- `backend/`: Express + MongoDB server code
- `frontend/`: React client (created in later lessons)

Lesson 0 deliverables:
- Initialize git repository
- Add branch strategy and project planning
- Add `.gitignore`
- Add `backend/.env.example`
- Confirm existing backend skeleton is ready
